# JellyPlay+ 0.1.5

Adds a preferred-language subtitle picker filter and improves playback options,
stream information, and MPV subtitle loading.

## Changes

- Add **Show only preferred subtitle languages** under **Language & Subtitles →
  Subtitles**. It defaults to off. When enabled, the on-demand subtitle picker
  shows the preferred subtitle language and ordered subtitle languages, plus
  **Off**. With no configured language preference, all tracks remain visible.
  Automatic selection, per-series memory, subtitle downloads, and timing retain
  their existing behavior. Backups and category resets include the setting.
- Combine playback engine, delivery method, and quality controls in the playback
  options panel. Keep the panel open while changing options and show the current
  delivery method. Disable quality changes during forced direct play.
- Send resolution limits as well as bitrate limits when resolving streaming
  quality, including separate cellular preferences.
- Separate source-file information from the active stream in playback details,
  avoiding stale source codec/HDR fields after transcoding.
- Make the detailed statistics panel scrollable and add a close button. Report
  ExoPlayer's actual decoder name and correct dropped-frame counters; refine MPV
  frame statistics.
- Queue MPV external subtitle loading until the file is ready and process one
  queued subtitle per main-queue turn so input can run between loads.

  store/settings tests. The pre-existing playback-session size guard failure
  was fixed without raising its ceiling or changing runtime behavior.

- Test-only subtitle and quality preferences were restored. Main-account settings
