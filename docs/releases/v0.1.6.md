# JellyPlay+ 0.1.6

Improves settings search, compact layouts, and touch interaction, and makes skip
prompt duration configurable.

## Changes

- Add search to settings selection lists with at least ten options. Match names,
  descriptions, and language codes, including Turkish character normalization.
  Opening search focuses the input and shows the keyboard.
- Search directly from **Add language…** in ordered audio/subtitle language
  preferences. Keep the input above the keyboard and append selections to the
  existing order without opening another sheet.
- Stack selected values below settings titles in narrow layouts. Keep settings
  search badges below descriptions so they do not squeeze titles.
- Make the navigation overflow menu scrollable so **Settings** remains reachable
  in short windows.
- Fix unresponsive lower rows in long settings groups on Android 13, including
  **Show Clock** and **Show Time Remaining**. Replace generic-path group clipping
  with a rounded outline and prevent continuous recomposition in row indexing.
- Default skip prompts to **10 seconds**. Add **Skip button duration** under
  **Playback → Advanced → Media Segments**, with 3, 5, 10, 15, 20, and 30 second
  choices. Include the setting in persistence, backups, resets, search, and
  transitions between media items.

## Validation

- Focused checks cover picker filtering, narrow layouts, overflow menu access,
  preference persistence, skip timers, and media-item transitions.
- The final follow-up run passed 44 tests: 4 core UI Android host tests,
  5 settings Android host tests, and 35 settings JVM tests. The long-group touch
  regression fails with the old clip on Android 13 at 440 dpi and passes with
  the corrected outline.
- Phone debug assembly, packaged Compose resources, Turkish resource coverage,
  and whitespace validation passed.
- On Redmi Note 11 Pro / Android 13 with the isolated test account, the Dev build
  opened the keyboard automatically, kept inline language search visible above
  it, and persisted both player clock and remaining-time toggles after touches.
- Tested preferences were restored. Both retained download hashes and the main
  account's policy, configuration, and watch-data hash matched their baselines.

Short landscape windows have Android host-test coverage. Physical landscape,
desktop runtime, and media playback were not exercised in this follow-up.
