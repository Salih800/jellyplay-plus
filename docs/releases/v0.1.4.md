# JellyPlay+ 0.1.4

Improves playback information and skip controls, adds live ExoPlayer/mpv
switching, and updates release asset naming while preserving older clients'
ability to discover updates.

## Changes

- Show codec information during offline playback as well as streaming.
- Refresh codec and resolution information when switching between direct play
  and transcoding. Wait for the new stream's metadata instead of displaying
  stale codec or HDR information from the original file.
- Use concise audio codec names such as AAC and Opus.
- Display HDR/Dolby Vision with the other playback information when available,
  removing the permanent corner badge. A format label does not certify native
  HDR output on the display.
- Show skip prompts initially for five seconds with a shrinking countdown bar.
  While the segment remains eligible, tapping the screen brings them back with
  the other controls without restarting the initial countdown.
- Show the active engine in the existing playback-method chip, for example
  `Exo · Transcode` or `MPV · Direct Play`.
- Switch between ExoPlayer and mpv from the playback-mode panel during local
  playback, retaining position, playback speed and pause state. This selection
  affects the current session without changing the saved default engine.
  The selector is hidden during casting and SyncPlay.
- Retain MPV pause and speed commands issued before its native video surface
  is initialized, fixing unwanted resume and a lost speed setting on engine
  changes.
- Prefer branded `jellyplay-plus-...-android-...apk` update assets while retaining
  support for the older filenames. Include a byte-identical compatibility copy
  for clients through 0.1.3.

- Android 9 (API 28) or newer; ARM64 phones and tablets.
- Uses the existing JellyPlay+ signing certificate for in-place updates.
- TV and desktop packages are not included in this phone release.
- `SHA256SUMS.txt` covers both identical APK assets.

## Validation

- Playback tests cover metadata transitions, codec labels, engine selection,
  session state, offline statistics and skip countdown behavior.
- Development-device checks used the separate `jellyplay-test` account on a
  Redmi Note 11 Pro running Android 13. Direct/transcode and ExoPlayer/mpv
  transitions were exercised during playback.
- Actual progress after an ExoPlayer-to-mpv switch at 1.25x advanced 41 seconds
  in 32.83 wall seconds (1.249x). A paused switch retained the 10:50 position.
- All 113 focused playback and update-feed tests passed. The release workflow's
  asset rename step was also exercised for two flavors and four ABIs, verifying
  identical legacy compatibility copies.
- The signed, optimized phone release build passed. Package/version/ABI,
  unchanged signing certificate, three provider authorities and six launcher
  shortcut targets were verified in the APK.
- Updating the device from 0.1.3 to 0.1.4 retained the test-account sign-in and
  original installation time. Playback and engine/method transitions were
  checked again in the optimized release build.

Native HDR display output was not tested. Codec fields may remain empty until
the active engine reports the new stream's format.
