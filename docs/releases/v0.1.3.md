# JellyPlay+ 0.1.3

Fixes notification and system-control-panel swipes changing player volume or
brightness, and documents the fork's additions at the top of the README.

## Changes

- Reserve the top touch edge for Android system gestures, including immersive
  playback with hidden system bars. A gesture that starts there stays excluded
  until the finger is released.
- Honor larger status-bar/system-gesture insets, with a 32 dp minimum touch band.
- Keep normal brightness, volume, horizontal seek, and side-edge swipes working.
- Keep the desktop gesture area unchanged.
- Add six Compose gesture regression tests covering both top corners, the next
  gesture after a system swipe, normal vertical/horizontal swipes, and an ordinary
  swipe entering the top band.
- Add README attribution, a fork feature summary, and versioned change history.

## Validation

- Six new gesture tests and five existing tap/double-tap tests passed.
- Player JVM compilation and Android debug APK assembly passed.
- Signed, optimized release APK assembly passed. Package/version/ABI, the
  unchanged signing certificate, all three provider authorities, and six launcher
  shortcut targets were verified in the packaged APK.
- Installed 0.1.2, signed in with the test account, and updated to 0.1.3 on the
  phone. The original installation time and authenticated session were retained.
- The fix was tested during actual video playback on a Xiaomi Redmi Note 11 Pro
  (2201116TG), Android 13: the notification shade and MIUI control center opened
  without changing player brightness or media volume.
- Swipes starting inside the reserved top band stayed inert; ordinary brightness
  and volume swipes worked in both directions.
- Repeated notification/control-center and normal brightness/volume checks in
  the optimized 0.1.3 release build during actual playback.
- Device testing used a restricted Jellyfin test account. The main account's
  settings and watch-state records matched before and after.
