# JellyPlay+ 0.1.2

Adopts the fork's final Android application ID: `com.salih800.jellyplay.plus`.

- Phone release: `com.salih800.jellyplay.plus`.
- TV release configuration: `com.salih800.jellyplay.plus.tv`.
- Existing development variants retain their legacy application IDs and data.
- Launcher shortcuts and provider authorities follow the final application ID.
- Baseline-profile generation and startup benchmarks target the new phone ID.
- Uses the same dedicated JellyPlay+ signing certificate as previous releases.
- Includes all download browsing, episode ordering, counts, and selection changes.

## Package

- Asset: `jellyplay-v0.1.2-phone-arm64-v8a.apk`.
- Version name: `0.1.2`; version code: `102`.
- Android 9 (API 28) or newer; ARM64 phones and tablets.

This application ID is separate from original JellyPlay, JellyPlay+ 0.1.0,
JellyPlay+ 0.1.1, and the Dev app. Settings and downloads do not automatically
transfer between these apps; keep existing apps and data if needed. The new app
requires adding the Jellyfin server again.
