# JellyPlay+ 0.1.0

First Android phone release of the JellyPlay+ fork, based on JellyPlay 0.11.4.

## Downloads and offline library

- Separate movies and series with category filters.
- Browse episodes under their series, with season groups when multiple seasons are downloaded.
- Keep episodes in ascending season and episode order regardless of download order.
- Show completed downloads / episodes available on the active Jellyfin server for series and seasons.
- Cache the last known episode totals per server and user for offline access.
- Select a whole series or season, including collapsed groups, with partial-selection indicators.
- Apply bulk actions to the selected downloads and confirm offline-library deletion.
- Retain failed selections and report failures instead of claiming deletion succeeded.
- Preserve download records when the media file cannot be removed.
- Improve active-download information and selection controls on narrow screens.

## Fork features

- JellyPlay+ branding and Turkish localization.
- In-app update checks target this fork's GitHub releases.

- Signed with the dedicated JellyPlay+ release certificate.
- Signing certificate SHA-256:
  `37c959f5074f5dd50d2c21c054da2a882e726582a8277c0094ce5a27a0828ef1`.
- The release installs separately from `JellyPlay+ Dev` (`com.raulshma.jellyplay.dev`);
  development-build settings and downloads remain in that separate app.
- An upstream JellyPlay installation uses the same application ID but a different
  signing certificate, so this APK cannot update it in place.
- TV and desktop packages are not included in this release.

## Validation

- 400 JVM tests passed: 91 downloads-feature tests, 291 database tests, and
  18 focused data-layer tests, including database migration and deletion failures.
- The changes were tested in the development build on a Xiaomi 2201116TG running
  Android 13: two real background episode downloads, numeric ordering, server
  totals, series/season selection, and confirmed bulk deletion.
- All 11 pre-existing device downloads were preserved during those tests.
- The signed, optimized release APK was installed alongside the development app
  on the same device and successfully opened the Turkish server setup screen.
  This release smoke check did not add an account or start playback.
- Full video playback, prolonged Doze, reboot recovery, and interrupted-network
  scenarios were not part of this validation.
